### ☁️ Cloud, DevOps & Infrastructure

- **[Cloud CI/CD Pipeline (GKE)](https://github.com/mayanktak15/cicd)**  
  Automated CI/CD — Docker builds → **Google Artifact Registry** → Kubernetes manifest updates → **GKE** deployment.

- **[bldin — Remote Browser Control Engine](https://github.com/mayanktak15/bldin)**  
  Mini TeamViewer for Chromium: spawns containerized **Playwright** instances and streams JPEG buffers over WebSockets in real-time.

- **[LLM-CalCulator](https://github.com/mayanktak15/LLM-CalCulator)**  
  Dockerized estimator for LLM inference hardware needs — VRAM, system RAM, KV cache, and GPU allocation.

---

### 🧠 Machine Learning, AI & Digital Forensics

- **[OCR-CHAT-PDF](https://github.com/mayanktak15/OCR-CHAT-PDF)**  
  Fully local, privacy-first PDF RAG platform — **Tesseract OCR** + semantic search over local LLM embeddings.

- **[MetaRecoverX](https://github.com/mayanktak15/MetaRecoverxfinal)**  
  Digital forensics tool targeting **XFS & Btrfs** — recovers deleted inodes, builds interactive timelines, exports forensic reports.

- **[Diabetes Risk Predictor](https://github.com/mayanktak15/ML-Project-Diabetes-Predication-system)**  
  Streamlit ML risk assessment app using diagnostic data from the Pima Indians dataset.

- **[Celebal Data Science Hub](https://github.com/mayanktak15/celebal-dataScience)** ⭐ *(also pinned above)*  
  Customer segmentation models — **K-Means, Scikit-learn, Pandas** — with EDA notebooks.
