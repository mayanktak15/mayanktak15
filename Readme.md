## 🚀 Key Projects

### ☁️ Cloud Deployment, DevOps & Infrastructure

* **[Cloud CI/CD Pipeline (GKE)](https://github.com/mayanktak15/cicd)**  
  Automated Continuous Integration & Continuous Delivery pipeline that builds container images with Docker, stores them in **Google Artifact Registry**, updates Kubernetes manifests, and deploys to **Google Kubernetes Engine (GKE)**.

* **[bldin — Remote Browser Control Engine](https://github.com/mayanktak15/bldin)**  
  High-performance real-time remote browser streaming engine (*mini TeamViewer for Chromium*). Spawns containerized **Playwright Chromium** instances and streams JPEG snapshot buffers over WebSockets.

* **[LLM-CalCulator](https://github.com/mayanktak15/LLM-CalCulator)**  
  Dockerized web-based estimator for Large Language Model inference hardware requirements (VRAM, system RAM, KV cache, and GPU allocation).

---

### 🌐 Web Engineering & Full-Stack Systems

* **[SDUI-Cars24](https://github.com/mayanktak15/SDUI-Cars24)**  
  Production-grade **Server-Driven UI (SDUI)** framework and marketplace layout built for Cars24 Mobile Engineering. Uses type-safe registry lookups binding server JSON strings to native UI components.

* **[Zeptox Platform](https://github.com/mayanktak15/zeptox)**  
  Full-stack grocery delivery platform clone built using **Python, Flask, SQLAlchemy, Tailwind CSS, and JavaScript**. Features cart management, order routing, and live tracking map integration.

* **[Urban Commerce (Shopi)](https://github.com/mayanktak15/Urban_Commerce)**  
  Modern e-commerce platform built with **React, Node.js, and MongoDB**. Includes authentication, product categorization, dynamic cart management, and toast notifications.

* **[NFT Warranty E-Commerce Platform](https://github.com/mayanktak15/NFT_Based_Ecommerse_Platform)**  
  Web3 e-commerce app attaching product warranties to **ERC-721 NFTs**. Features MetaMask wallet integration, Twilio SMS notifications, and secondary market warranty transfers.

---

### 🧠 Machine Learning, AI & Digital Forensics

* **[OCR-CHAT-PDF](https://github.com/mayanktak15/OCR-CHAT-PDF)**  
  Fully local, privacy-focused PDF OCR and Retrieval-Augmented Generation (**RAG**) search platform. Extracts text from scanned PDFs via Tesseract OCR and performs semantic search over local LLM embeddings.

* **[MetaRecoverX](https://github.com/mayanktak15/MetaRecoverxfinal)**  
  Digital forensics tool targeting **XFS and Btrfs filesystems**. Recovers deleted inodes/metadata journals, builds interactive file timelines, and exports structured forensic reports.

* **[Docify Online](https://github.com/mayanktak15/Docify)**  
  Medical consultation and AI chatbot assistant built on **Python and Flask**, optimized for efficient low-latency execution on CPU-only Linux systems.

* **[Diabetes Risk Predictor](https://github.com/mayanktak15/ML-Project-Diabetes-Predication-system)**  
  Streamlit-based ML risk assessment app using medical diagnostic parameters from the Pima Indians dataset.

* **[Celebal Data Science Hub](https://github.com/mayanktak15/celebal-dataScience)**  
  Data science project repository featuring **Customer Segmentation** models (K-Means, Scikit-learn, Pandas) and EDA notebooks.
